# BM3D: Collaborative Filtering of Correlated Noise

A from-scratch Python implementation and experimental reproduction of the method described in:

**Mäkinen, Azzari, and Foi, “Collaborative Filtering of Correlated Noise: Exact Transform-Domain Variance,” IEEE Transactions on Image Processing (2020).**

The accompanying Jupyter notebook implements the paper's correlated-noise model, transform-domain variance calculations, block matching, collaborative filtering, and Global Fourier Thresholding (GFT) with refiltering.

> **Reproduction note:** This repository contains an implementation/experimental reproduction, not a claim of an exact reproduction of every experiment in the paper. The notebook's main PSNR experiment uses a reduced configuration (8 images, 3 selected kernels, 3 noise-variance levels, and 2 noise realizations), rather than the paper's full experimental protocol.

## Overview

Conventional BM3D-style filtering commonly uses an approximate, position-independent transform-domain noise variance. For correlated noise and groups of spatially separated patches, this approximation can be inaccurate because the noise across matched patches may be correlated.

The paper's central idea is to calculate the **exact transform-domain variance for each coefficient and matched patch group**. This implementation compares:

- **Old BM3D:** uses the conventional variance approximation from Eq. (8).
- **New BM3D:** uses the exact transform-domain variance from Eq. (14).

The notebook also implements bias-corrected block matching and Global Fourier Thresholding followed by refiltering.

## Implemented components

| Component | Paper reference | Description |

| Conventional variance | Eq. (8) | Implements the old constant variance approximation. |
| Exact transform-domain variance | Eq. (14) | Computes coefficient- and patch-group-dependent variance. |
| Fast variance approximation | Eq. (29) | Uses an energy-conservation approximation for remaining transform planes. |
| Block matching | Eq. (15), (22), (23) | Supports standard and bias-corrected matching (`γ = 3`). |
| Hard-thresholding | Eq. (25) | Applies thresholds using coefficient-specific variances. |
| Wiener filtering | Eq. (26) | Applies variance-aware Wiener shrinkage. |
| Aggregation | Eq. (27)–(28) | Uses block-specific aggregation weights. |
| Global Fourier Thresholding | Eq. (30)–(31) | Detects residual frequency components using a three-sigma test and morphological dilation. |
| Refiltering | Fig. 13 | Implements the multi-stage HT/GFT/Wiener refiltering workflow. |

## Experimental configuration

The notebook's reduced Section VII-style PSNR experiment uses:

| Setting | Value |
|---|---:|
| Input images | 8 |
| Noise kernels tested | `gw`, `g1`, `g3` |
| Noise variance (`σ²`) | `0.001`, `0.01`, `0.02` |
| Noise realizations per setting | 2 |
| Patch size (`N`) | 8 |
| Search window | 7 |
| Group size (`M`) | 4 |
| Aggregation step | 8 |
| Fast variance grid (`Nf`) | 8 |
| `K` | 1 |
| PSNR border trim | 16 pixels |

The experiment compares old and new BM3D using the same noisy realization and reports the PSNR difference. A separate visual-comparison cell uses a larger/slower parameter configuration.

**Important:** These reduced settings are for computational feasibility and should not be described as the paper's full Table III evaluation. To move closer to the paper's experiment, extend the kernel list, number of noise realizations, and algorithm parameters as appropriate, then rerun the complete evaluation.

## Expected workflow

1. Load and normalize the clean grayscale images.
2. Construct a selected noise kernel.
3. Generate correlated noise and create the noisy observation.
4. Compute the noise PSD.
5. Run old BM3D using the conventional variance approximation.
6. Run new BM3D using exact transform-domain variance.
7. Compare denoised outputs using PSNR and visual inspection.
8. Apply GFT and refiltering in the relevant notebook experiments.

## Evaluation

The notebook uses **Peak Signal-to-Noise Ratio (PSNR)** to compare the clean reference image with the noisy and denoised images. The reduced PSNR experiment trims a 16-pixel border before calculating PSNR.

The notebook also produces visual comparisons and diagnostic plots for the noise kernels, transform-domain variance, block-matching bias, GFT, and refiltering stages.

## Implementation notes

The notebook documents several implementation corrections, including:

- Per-coefficient DCT-basis FFT handling in the exact variance calculation.
- Correct energy summation for the fast variance approximation.
- Patch extraction and coordinate handling in block matching.
- PSD scaling and kernel-support padding in GFT.
- Block-specific aggregation weights for hard-thresholding and Wiener filtering.
- A multi-stage refiltering pipeline.

These are implementation notes recorded in the notebook; numerical performance should be assessed by running the experiments on the intended dataset and reporting the resulting measurements.
